# cupmotion — моушен-студия для Claude Code

> Напиши Claude «сделай промо моего приложения в 3д» — получишь готовый MP4 со звуком. Ролик собирается кодом, рендерится в 60 fps и сводится по громкости под соцсети.

**Установка (две команды в терминале, потом перезапусти Claude Code):**

```bash
claude plugin marketplace add yearofcodeking/cupmotion
```

```bash
claude plugin install cupmotion@cupmotion
```

Подробности, требования и примеры запросов — ниже. Лицензия MIT, пользоваться и дорабатывать можно свободно.

---

Ролик собирается кодом: это HTML-страница, где каждый кадр — функция времени.

Внутри:
- **Правила режиссуры**: камера с глубиной, типографика в действии, звук из материала, а не вжухи.
- **Плавность и связность**: три отдельных справочника — плавность камеры, плавность движения объектов и текста, связность кадров. Кадр идёт за кадром,
  без склеек и эффектов-переходов (кроссфейдов, вайпов): смена места делается движением внутри одного мира. Жёсткий монтаж — только если его попросили.
  Каждый стык — звено цепочки смысла («А → потому что → Б»): переход держится на одном и том же объекте, а не на «выскочившей» подмене.
- **Каталог стилей**: 30+ стилей — от Apple-минимализма и вирусного SaaS-лаунча (5 веток) до Y2K, пластилина, ризографа, документалки, люкса и трейлера.
  Назвал стиль словами («как у эппл», «хром», «как в тиктоке») — подхватит его; не назвал — выберет по теме («ролик про кофе» → зерно и ризограф) и скажет, что выбрал.
- **Звук под стиль**: у каждого стиля свой жанр музыки, темп, тембр звуков и пространство; рецепты синтеза UI-кликов, тумблеров, ударов, райзеров и саб-дропов.
- **Словарь триггеров**: слова в запросе сами подключают нужные промпты, стили и сайты. Написал «в 3д» — подтянутся
  промпт премиального 3D, справочник по Three.js и сайты с бесплатными моделями. Написал «пиксель», «рисованный», «неон», «объяснялка», «клип» —
  подтянется своё.
- **Библиотеки с проверкой на seek**: GSAP, Flubber, Rough.js, three + postprocessing — готовые рецепты, которые дают один и тот же кадр при любой перемотке.
  Для tsParticles, WebGL Fluid, Hydra, LYGIA и других записано, почему они ломают рендер или лицензию, и чем их заменить (`references/libs.md`).
- **Скрипты**: рендер кадров через системный Chrome, сведение до −14 LUFS, листы для ревью, замер долей трека, «уши» (расшифровка речи и анализ звука).
- **Цикл проверки**: Claude сам смотрит свои кадры, ставит оценки и чинит худшее, прежде чем отдать ролик.

## Что нужно заранее

| Что | Проверить | Поставить (Windows / macOS / Linux) |
|---|---|---|
| Node.js 18+ | `node -v` | `winget install OpenJS.NodeJS.LTS` / `brew install node` / [nodejs.org](https://nodejs.org) |
| ffmpeg | `ffmpeg -version` | `winget install Gyan.FFmpeg` / `brew install ffmpeg` / `sudo apt install ffmpeg` |
| Chrome или Edge | есть в системе | на Linux — Chromium |

Без Node не заработает ни подбор промптов, ни рендер, так что проверь его первым. После установки чего-то из таблицы перезапусти терминал.

## Установка

Одна команда в терминале:
```bash
claude plugin install cupmotion --marketplace yearofcodeking/cupmotion
```
Если твоя версия Claude Code не знает флаг `--marketplace`, то двумя командами:
```bash
claude plugin marketplace add yearofcodeking/cupmotion
```
```bash
claude plugin install cupmotion@cupmotion
```
Перезапусти Claude Code — и можно просить ролик.

**Первый ролик.** Руками больше ничего не настраиваешь. Перед первым рендером Claude сам проверит компьютер скриптом `doctor`
и один раз поставит `playwright-core` (библиотеку, через которую он «фотографирует» кадры) в папку `~/.cupmotion`. Браузер отдельно не качается:
берётся твой Chrome или Edge. Если чего-то не хватает, Claude скажет, что поставить.

**Рендер занимает минуты.** 15 секунд в 60 fps — это около 1800 снимков кадра. Так и должно быть, ничего не зависло.

**«Уши» — по желанию.** Это расшифровка речи и анализ звука готового ролика (громкость, акценты по кадрам), плюс замер долей твоего трека.
Нужен Python 3.9+. Напиши Claude «поставь уши для cupmotion»: он поставит библиотеки, а при первом прослушивании скачает модель Whisper (~0,5 ГБ).

Обновление: `claude plugin marketplace update cupmotion`. Удаление: `claude plugin uninstall cupmotion@cupmotion`.

## Как пользоваться

Просто проси ролик своими словами:
- «сделай промо моего приложения на 15 секунд»
- «моушен про кофе в бумажном стиле»
- «объяснялка, как работает инфляция, вертикально для шортс»
- «логотип в 3д, 5 секунд»
- «клип под этот трек» (и приложи файл)

Или вызови явно: `/cupmotion <тема>` (полное имя команды — `/cupmotion:cupmotion`).

Claude не будет засыпать вопросами: придумает концепт, соберёт раскадровку, отрендерит, проверит кадры и отдаст файл.
Хочешь согласовать сценарий до рендера — так и скажи.

## Какие слова что включают

Сначала хук понимает, что ты просишь именно ролик: по словам «ролик», «видео», «моушн», «промо», «клип», «объяснялка», «шортс», «reels», «мультик».
«Анимация», «интро» и «заставка» тоже считаются, но не тогда, когда в сообщении код интерфейса: «CSS-анимация кнопки» студию не включит.
Потом по словам из таблицы подключается нужное. «3д», «2,5д» и «шоурил» срабатывают даже без слова «ролик».

| Пишешь | Подключается |
|---|---|
| 3д, трёхмерный, объёмный, three.js, блендер | премиальный 3D, справочник по 3D, сайты бесплатных моделей |
| 2,5д, параллакс · 2д | многоплановая глубина · плоская 2D |
| рисованный, от руки, скетч, карандаш | рисованный стиль |
| бумажный, коллаж, стоп-моушн | бумажный коллаж |
| вектор, флэт · комикс, стикеры · пиксель, 8-бит | вектор · комикс · пиксель-арт |
| кинетическая типографика, титры · неон, киберпанк, HUD | типографика · неон |
| интерфейс, UI, приложение, сайт, курсор | моушен интерфейсов |
| промо, запуск, реклама, продукт, бренд | промо продукта |
| объяснялка, шортс, новости, история | объяснялки |
| карта, маршрут · график, инфографика, счётчик | карты · данные |
| клип, песня, под трек | клип под музыку |
| логотип, заставка, интро · шоурил | лого · шоурил |
| SaaS, стартап, лаунч приложения | вирусный лаунч-ролик и пять веток стиля |
| как у эппл, градиент, глянец, хром, стекло, пластилин, изометрия, ризограф, швейцарский, брутализм, документалка, журнальный, жидкий, ло-фай, тикток, люкс, трейлер | свой стиль и звук под него |
| стиль не назван | выбор по карте «тема → стиль» |
| любой ролик | плавность камеры, плавность объектов и текста, связность кадров без склеек и со смыслом стыков, звук под стиль |
| gsap, flubber, rough.js, postprocessing, bloom (и другие библиотеки по имени) | вердикт и рецепт из `libs.md` |
| референс, в стиле, ссылка на видео | разбор референса |
| персонаж, герой, маскот | один герой в разных позах |
| «2 минуты», длинный, фильм | бриф длинного ролика |
| звук, музыка, саунд, озвучка | звук и фоли |


Короткий запрос подключает всё, что в нём названо. Длинный текст (больше 600 знаков, например вставленный бриф) не включает маршрут по одному случайному слову:
нужны два слова маршрута (повтор слова или слово сразу после «стиль» засчитывается), и подкладывается не больше 5 маршрутов и 4 стилевых разделов. Что отброшено, хук называет одной строкой. Пороги — `longMessage`, `maxRoutes`, `maxStyles` в `routes.json`.

## Свои настройки

- **Память плагина** — файл `~/.claude/cupmotion.local.md` (для предпочтений по моушену: «без неона», «всегда медленнее», «только 9:16»). Автор канала https://t.me/faizullin_ai напоминает: она есть, пользуйтесь, чтобы правила не спорили друг с другом.
- **Личные правила** — тот же файл `~/.claude/cupmotion.local.md`. Всё, что там написано, подкладывается к каждому запросу про ролик и важнее общих правил.
  Например: «всегда 9:16», «бренд — оранжевый #E8572A и шрифт Manrope», «проекты складывай в D:/videos».
- **Это всё лежит у тебя на компьютере.** `~/.claude/cupmotion.local.md` и `cupmotion.routes.json` создаются на каждой машине отдельно и в репозиторий не попадают:
  кто ставит плагин, получает только правила, стили и скрипты, а твои настройки и память не видит. Обновление плагина их не трогает.
- **Свои слова** — файл `~/.claude/cupmotion.routes.json`. Обновление плагина его не трогает. Пример: «тикток» считать просьбой о ролике,
  а к 3D добавить слово «воксели»:
  ```json
  { "video": ["тикток"], "routes": [ { "id": "3d", "match": ["воксел"] } ] }
  ```
  Можно завести и свой маршрут: `id`, `label`, `match` (регулярки), `styles`, `refs`, `sites`, `tips` — как в `skills/cupmotion/routes.json`.

## Claude.ai (сайт и приложение)

Скачай `cupmotion-skill.zip` из этого репозитория и загрузи в настройках Claude, в разделе навыков (Skills). Там нет хуков, поэтому триггеры Claude читает из `routes.json` сам.
Правила, стили и промпты работают; рендер MP4 скриптами рассчитан на Claude Code на твоём компьютере.

## Как устроено

```
cupmotion/
├─ .claude-plugin/marketplace.json      каталог (чтобы ставилось одной командой)
└─ plugins/cupmotion/
   ├─ hooks/route.mjs                   читает каждое сообщение, ищет триггеры, подкладывает нужное
   └─ skills/cupmotion/
      ├─ SKILL.md                       правила и порядок работы
      ├─ routes.json                    словарь: слова → стили, справочники, сайты
      ├─ references/                    стили, 3D, промо, UI, объяснялки, клипы, звук, критика, экспорт,
      │                                 flow-brief (конспект плавности и стыков), camera-motion, object-motion, continuity (стыки и их смысл), palette (цветовая гамма),
      │                                 launch-video (вирусный SaaS-лаунч), sound-styles (звук под стиль), libs (библиотеки: что брать и как)
      └─ scripts/                       render, mix, review, beats, listen, doctor
```

Хук молчит, если сообщение не про видео: «почини парсер» ничего не подключит. Внутри одного разговора каждый блок правил
подкладывается один раз, дальше только короткая отсылка. Если кажется, что хук не работает, запусти Claude с переменной `CUPMOTION_DEBUG=1`:
ошибки хука появятся в выводе.

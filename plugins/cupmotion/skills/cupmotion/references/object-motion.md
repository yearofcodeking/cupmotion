# Плавность движения объектов и текста

Всюду `x = clamp((t − t0)/dur, 0, 1)`. Пометка **[оценка]** — число выведено практикой, это отправная точка: подбирать по кадрам.
Тут про то, как движется содержимое кадра. Про камеру — `camera-motion.md`, про переход между местами — `continuity.md`.

## 1. Выбор кривой по роли движения
| Роль | Кривая | Почему |
|---|---|---|
| Вход в кадр или на место | ease-out: `outQuart = 1−(1−x)⁴`, `outQuint = 1−(1−x)⁵`, `outExpo = 1−2^(−10x)` | объект приходит на скорости и мягко садится: за первые 20–30 % времени проходит 70–85 % пути |
| Уход из кадра | ease-in | разгоняется и уходит; тормозить перед краем кадра нельзя |
| Перемещение по экрану, остаётся в кадре | ease-in-out (симметричный) | разгон и торможение |
| Непрерывное вращение, бегущая лента, дрейф фона | linear | у такого движения нет начала и конца |
| Вес, посадка, физический объект | пружина (см. §3) | инерция и перелёт |
- Один и тот же easing на всех элементах — признак «дешёвой» анимации. Входам — быстрые ease-out, выходам — ease-in, перемещениям — in-out.
- Встроенный CSS-`ease-out` слабоват: для эффектного входа брать `outQuart`/`outQuint`/`outExpo`.
- Кривая включается на каждый сегмент движения, а не на ролик целиком.

## 2. Длительности
- Вход обычно длиннее выхода (приход ≈ 225 мс, уход ≈ 195 мс в интерфейсах); дольше 400 мс интерфейсное движение кажется вялым.
- В видео зритель не нажимает кнопок, поэтому темп можно замедлить: вход 0.4–0.8 с, выход 0.25–0.5 с **[оценка]**.
- Длительность растёт с расстоянием и размером: большой объект и дальний путь получают больше времени. Лёгкое — быстрее, тяжёлое — медленнее и с бóльшим разгоном.
- Зритель видит ролик один раз: основная смысловая деталь должна успевать, поэтому быстрые движения — медленные смыслы (см. тайминг в ядре).

## 3. Пружины
- Степень демпфирования `ζ = c/(2·√(k·m))`: `ζ = 1` — без перелёта (критическое затухание), `ζ < 1` — перелёт, `ζ > 1` — вялое. Жёсткость `k` задаёт скорость.
- Параметры «длительность + bounce» удобнее сырых чисел: при `m = 1` жёсткость `k = (2π/длительность)²`, демпфирование `c = 4π·(1−bounce)/длительность` при `bounce ≥ 0`.
  `bounce ≈ 0` — без отскока (серьёзные и информационные кадры), ≈ 0.15 — чуть живее, ≈ 0.30 — заметный отскок, выше 0.4 — слишком.
- **Перелёт оправдан**, когда тон игровой, объект физический или завершается жест («посадка» карточки, значка). Не на всём подряд.
- **Пружина сохраняет и позицию, и скорость при смене цели**; ease-in-out при смене цели даёт рывок. Если цель изменилась, интегрировать пружину по состоянию,
  а не пересчитывать кривую с нуля. Для `seek(t)` без состояния — прогнать пружину офлайн с фиксированным шагом и закэшировать массив.
- Устойчивых колебаний около 0.2 Гц избегать: на них человек особенно чувствителен (укачивает).

## 4. Принципы живого движения
- **Slow in / slow out:** ничто не стартует и не останавливается мгновенно (кроме механики и намеренного «удара»).
- **Дуги.** Живое движение идёт по кривой; чем быстрее, тем она прямее. Прямая — для механики и интерфейсных слайдов. Получить дугу: x и y с разными кривыми или фазой
  (`y = e(x)`, `x = e(x − 0.1)`), либо вести по безье или окружности.
- **Инерция и follow-through.** Части объекта продолжают двигаться после остановки главного и стартуют в разное время: вторичный элемент (хвост, тень, подпись)
  идёт по тому же пути с задержкой 2–6 кадров (~0.08–0.25 с) **[оценка]** и чуть мягче, либо второй пружиной, ведомой первой.
- **Подготовка (anticipation).** Перед основным движением короткий откат в обратную сторону: отдельный сегмент 80–150 мс, 3–8 % пути **[оценка]**.
  Без него действие внезапно. Для текста и интерфейса почти не нужна.
- **Сжатие и растяжение** по скорости с сохранением объёма: `sx = 1 + k·|v|`, `sy = 1/sx`, `k ≈ 0.02–0.08` на нормированную скорость **[оценка]**; вытянуть вдоль скорости,
  сжать в момент контакта. В материале «бумага», «стекло», «металл» — не применять.
- **Вес и контакт.** Предмет, скользящий по поверхности без тени и контакта, выглядит как наклейка: добавить контактную тень, реакцию поверхности, остаточное движение после касания.
- **Staging.** Один главный элемент в кадре движется ярче, остальные тише и менее контрастны. «Если анимировано всё, ничто не выделяется».

## 5. Последовательность и порядок
- **Stagger (каскад).** Шаг между элементами 50–100 мс; слишком большой шаг встречается чаще слишком малого. Текст по буквам: 30–50 мс на символ — «текуче», 100+ мс — «драматично».
  Порядок: первый→последний, от центра, от краёв, волной по сетке. Общее время каскада ограничить: `delay_i = min(i·step, maxTotal)` (потолок ≈ 0.6–0.8 с **[оценка]**) или раскладывать задержки по кривой.
- **Иерархия.** Первым движется главный элемент, остальные позже и с меньшей амплитудой. Единый ритм на весь кадр; не все стартуют одновременно.
- **Единое направление.** Если элемент въехал сверху, он и уходит вверх, а не вбок. Один и тот же объект остаётся «тем же» между состояниями (миниатюра раскрывается,
  а не подменяется другим). Входы в сцене идут с общего вектора.
- **Каждое движение связано с чем-то на экране:** из чего-то и во что-то. Движение без источника и без цели — мусор.
- Не делать всё fade-ом: появление = сдвиг + масштаб + прозрачность, а не одна прозрачность.

## 6. Размытие, кадры, субпиксели
- **Motion blur 180°:** выдержка = половина интервала кадра. Меньше — «дёрганое», больше — «смазанное». Для кадра `n` взять N подкадров в окне
  `t_k = (n + (k/N − 0.5)·s)/fps`, `s = 0.5` для 180°, усреднить. Подкадров хватает, когда сдвиг между соседними ≲ 1–2 px **[оценка]**; иначе вместо размытия «призраки».
- **Temporal aliasing (эффект колеса).** Быстрое периодическое вращение без размытия кажется медленным, застывшим или обратным. Условие: за кадр поворот меньше половины углового шага между
  одинаковыми элементами; для N спиц `ω < fps/(2N)` об/с. Лечится размытием и ограничением скорости.
- **Субпиксельные координаты.** Не округлять положение текста и объектов до целого пикселя при плавном движении (мерцание букв и «ступеньки»). Анимировать `transform`/`opacity`, не `left/top`.
  Округлять можно после остановки. Исключение — пиксель-арт и «на двойках» (стили в `styles.md`, `paper-collage.md`): там шаг намеренный.
- Для 60 fps размытие и честные подкадры (`--sub 2`) решают подрагивание медленных движений.

## 7. Текст
- **Разбиение:** строка за строкой — для длинного, слово за словом — для заголовка в 3–8 слов, по буквам — только для логотипа и совсем коротких заголовков. Длинные задержки каскада замедляют чтение.
- **Не двигать читаемую строку во время чтения.** Вход и выход 0.3–0.5 с, потом текст неподвижен и держится столько, сколько нужно на прочтение вслух. Для казуальной моушн-графики ориентир
  12–15 символов/с **[оценка]** (профессиональные титры допускают до 20), т. е. заголовок ~20 символов виден ≥ 1.5 с после появления. Правило ядра `(слов ÷ 3) + 0.5 с` остаётся минимумом.
- **Что интерполировать:** сдвиг на 10–30 % высоты строки + прозрачность + масштаб 0.92 → 1 на `outQuart`/`outExpo`; трекинг широкий → нормальный (0.2 em → 0) на `outExpo` — выглядит как «собирается»;
  размытие на входе 8–12 px → 0 **[оценка]**.
- Без стробирования: не мигать чаще 3 раз в секунду. Гротеск читается в движении лучше тонких засечек.

## 8. Признаки «дешёвой» анимации
Всё появляется только fade-ом · все стартуют одновременно · один easing везде · резкие остановки (ease-in без ухода за кадр, линейный стоп) · нет инерции и follow-through ·
объекты скользят без тени и контакта · пружины с отскоком на всём · анимация без смысла и «для красоты» · округление координат · читаемый текст в движении.

## 9. Проверка
- Контакт-лист на кадрах входа и посадки: видна ли кривая (быстрый старт, мягкая посадка), нет ли «телепортации» между соседними кадрами.
- График положения и скорости каждого главного объекта: нет скачков скорости, нет остановок в ноль без причины, перелёт не больше задуманного.
- Задержки каскада: суммарное время ≤ потолка, порядок читается.
- Текст: каждая фраза успевает прочитаться вслух после того, как перестала двигаться.
- Смотреть в движении (проба с `--sub 2`), а не только по стоп-кадрам.

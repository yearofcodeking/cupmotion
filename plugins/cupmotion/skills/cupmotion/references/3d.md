# 3D: сцена в коде, готовые модели и подготовка

## Как строить 3D-ролик
- **Сначала придумать главный кадр** (signature shot) и строить к нему весь ролик.
- **Кинокамера, а не OrbitControls:** на каждый шот одна названная траектория — проезд, кран, облёт, наезд, перевод фокуса;
  разгон и торможение плавные, камера не проходит сквозь геометрию.
- **Свет и материалы:** ключевой, заполняющий и контровой свет с мягкими тенями; окружение для отражений (RoomEnvironment через PMREM);
  туман для глубины; физические материалы с разной шероховатостью; тонмаппинг ACES. Ничего не должно выглядеть «материалом по умолчанию».
- **Объекты реагируют друг на друга:** то, во что попали, сдвигается; то, что рядом, подсвечивается. Пружины или простая физика, не линейные твины.
- **Запрещено:** материалы и свет по умолчанию, парящие текстовые подписи, свечение на всём, «медленно крутящийся объект» как вся идея, вид техдемо.
- **Сборка:** один HTML, three.js; режим рендера, где каждый кадр считается из времени (сидовая случайность, без часов), чтобы его можно было
  захватить `scripts/render.mjs`. По кадру на шот — посмотреть и исправить плоское, зубчатое, обрезанное, нечитаемое.
- **Грабли:** задать shadow bias, иначе поверхности в полосах; near и far плоскости держать узкими, иначе дальнее мерцает; сидировать все случайности,
  иначе рендер не совпадёт с превью. three.js с CDN требует интернета при рендере — при проблемах поставить `three` локально.
- Без видеокарты 3D рендерится медленно: держать сцену лёгкой, проверять реальный темп рендера пробой.

## Готовые модели: где брать
Сведения о библиотеках собраны по их документации, сами файлы не проверялись. Перед использованием открыть страницу выпуска и проверить лицензию файла.
**Скачивание — только с разрешения пользователя. Аккаунты не создавать.**

| Задача | Источник | Что учесть |
|---|---|---|
| Реалистичные предметы | [Poly Haven](https://polyhaven.com/models) | glTF, CC0, без регистрации |
| Стилизованные наборы | [Kenney](https://kenney.nl/assets/category:3D) | 3D-наборы, GLB, CC0; можно скачать без пожертвования |
| Персонажи и риги | [Quaternius](https://quaternius.com/) | бесплатные выпуски часто FBX / glTF; лицензия у каждого выпуска своя |
| Реальные сканы | [ambientCG](https://ambientcg.com/list?type=3d-model,terrain) | CC0; формат смотреть в ZIP |
| Конкретные устройства | [Sketchfab](https://sketchfab.com/3d-models?features=downloadable&sort_by=-likeCount) | скачивание только с аккаунтом пользователя |
| Бесплатные по формату | [CGTrader](https://www.cgtrader.com/3d-models?free=1) | проверять реальную нулевую цену |
| Стилизованные герои | [KayKit Adventurers](https://kaylousberg.itch.io/kaykit-adventurers) | бесплатная часть — 5 моделей CC0 |
| Технический резерв | [Khronos glTF Samples](https://github.com/KhronosGroup/glTF-Sample-Assets) | лицензия в README каждого ассета |
| Разное | [Poly Pizza](https://poly.pizza/explore) | только вручную: условия запрещают автоматическую загрузку |
Формат — GLB / glTF (GLB удобнее: один файл).

## Подготовка модели к сцене
1. Проверить сам файл: mesh, UV, текстуры, материалы, риг и анимации. Открыть и отрендерить файл, а не смотреть превью на сайте.
2. Привести единицы, масштаб, оси, ориентацию и pivot. Проверить нормали, толщину, прозрачность, roughness / metalness, color space текстур.
3. Проверить текстуры после загрузки (пути, размеры, alpha). Тяжёлые меши облегчить, сохранив силуэт.
4. Свет и тени под материал: пластик, металл и стекло ведут себя по-разному.
5. Шарниры: крышка ноутбука вращается вокруг оси петли, а не весь корпус.
6. В конце результата перечислить источники: автор, ссылка, формат, условия, дата проверки, изменения.

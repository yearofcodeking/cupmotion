# Интерфейс в движении: курсор, состояния, морфинг, 2D / 2.5D / 3D

## Морф одной формы (идея, которая работает)
Один элемент никогда не режется: кнопка → загрузка → галочка → плеер → ползунок → переключатель → вкладки → график → палитра команд → уведомление → снова кнопка.
Меняются размер, радиус и цвет, содержимое сменяется за коротким размытием, курсор управляет каждым изменением настоящими кликами и перетаскиванием.
Светлый тёплый фон, один акцент. Пружины с крошечным перелётом. Последний кадр равен первому — петля без стыка.
Технически: значение с несколькими целями — сумма пружин по одной на каждое изменение; у индикатора вкладок передний и задний край на разных пружинах
(он тянется); перетаскивание — значение считается из позиции курсора, после отпускания пружинит обратно.
Грабли: не ставить `will-change` на то, что масштабирует камера (текст мылится); текст внутри морфящегося контейнера входит после начала морфа
и уходит до следующего; в петле совпадает и позиция курсора, и его скорость.

## Действие и результат
- Каждый эпизод — понятная задача: выбрать, настроить, перетащить, запустить, показать результат. Одно правдоподобное приложение с последовательными данными.
- Единые радиусы, тени и толщины линий. В одном действии 1–3 главных элемента управления.
- **Курсор ведёт действие:** наведение → реакция цели → нажатие → изменение → читаемый результат. Попадание — кончиком стрелки.
  Курсор не закрывает подпись кнопки и результат.
- Состояния связаны причинно (наведение, нажатие, обработка, успех); успех не раньше конца процесса; индикаторы одной операции идут вместе.
- Перетаскивание: точка захвата сохраняется, карточка приподнимается и идёт по дуге, зона назначения подсвечивается, при отпускании мягко встаёт в слот.
- Результат растёт из элемента, который его вызвал. Морф меняет реальные размеры формы, а не растягивает интерфейс вместе с текстом.

## Один интерфейс в трёх режимах
| Режим | Что меняется |
|---|---|
| 2D | плоские панели и карточки, объём не имитировать |
| 2.5D | те же плоские панели разведены по глубине, камера раскрывает параллакс; боковин нет |
| 3D | у объектов настоящая толщина и кромка; объём подтверждают свет, тени и пролёт камеры |

## Координаты и проверка
- Разделять мир сцены и экранный слой. Если курсор работает с объектом в 3D — его экранная точка из проекции якоря с учётом камеры.
- Курсор, захват, состояния и задержки — один таймлайн, перемотка назад работает.
- Проверить в темпе: понятность действия, точность захвата, завершение перетаскивания, синхрон прогресса, читаемость текста интерфейса.

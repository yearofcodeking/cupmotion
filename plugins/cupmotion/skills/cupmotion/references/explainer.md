# Объяснялки: новостной шортс и 2D-мультобъяснялка

Правила выведены из реальных правок заказчика за 5 кругов.

## Сценарий (если пишу сам)
- 40–45 с ≈ 105–115 слов озвучки (~135 слов/мин). 30 с ≈ 75–80 слов.
- Одна визуальная идея на предложение, 3–5 с на экране. Объяснять «для умного десятилетки»: короткие фразы, конкретные предметы.
- Попросили «проще» — убрать понятие, а не переформулировать.
- Абстрактная логика (таймлайны, парадоксы, вероятности) — **один постоянный визуал, который достраивается по шагам**.
  Объяснялка, где картинку всё время уводили, провалилась.
- Новостной шортс: крючок (дата + шокирующее число) → понятное сравнение («вдвое больше экономики России») →
  конкретная цепочка причин → параллель сегодня (названная компания и цифры) → короткая ироничная концовка.
  Каждую цифру проверять поиском, источники называть.

## Новостной шортс 9:16 (журнальная подача)
- Фон: уголь ~#222 и бумага ~#ECEBE7, у каждого мелкое зерно + лёгкие пятна + виньетка.
  Ч/б фото-подложки затемнены до 30–45 % под текстом.
- Цвет: чёрный / белый / серый + **один красный #C8181F** (потеря, предупреждение, акцент).
  Знак и цвет совпадают со смыслом: расходы — «−$500B» красным и деньги видимо утекают, а не растущее белое число.
- Шрифт: контрастная антиква для цифр, дат, заголовков и финальной строки; гротеск для подписей.
- Ассеты: ч/б гравюра / полутон-вырезки с редким красным.
- Логотипы — только официальные файлы. Реальные люди — реальные пресс-фото, ч/б, с правильной текущей должностью.
- Одна сцена — одна мысль: рисующийся красный график, большой счётчик, силуэт страны ×2 = компания,
  круги с честной площадью для сравнения оценок, зачёркнутые красным имена.

### Мелкая жизнь в каждой графике (никогда не суетливо)
- Круговой счётчик рисуется по часовой стрелке от 12 часов, **число появляется, когда круг прорисован на ~80 %**; потом может довернуться сектор.
- Бегущие цифры: вертикальное размытие пропорционально скорости, резкость возвращается, когда число встаёт.
- Красные «чернила» растекаются внутри силуэта (карта, лого) по шумному полю расстояний — частичное покрытие ~35 %, не полная заливка.
- Линейный график: красная линия рисуется, под ней слабая красная заливка, ведущая точка мягко пульсирует.
- Фото: медленный наезд ~7–8 % за 3 с внутри скруглённой карточки.
- Физические мелочи: песочные часы качнулись на градус при приземлении, искры от горящих денег, облако дрейфует.

### Тайминг и глубина
- Появления 0.5 с (размытие → чёткость + подъём), попы 0.6 с с лёгким овершутом, панели 0.6 с.
- Любой текст / графика читается **≥ 1–1.5 с** до смены сцены. Ничего не мелькает.
- Три слоя: фон наезжает ~1.2 %/с, объекты всплывают ~12 px/с, текст неподвижен.
- Финал — спокойный кадр: последняя строка антиквой, ключевое слово красным курсивом.
- Не дублировать подписью то, что уже написано на графике.

## 2D-мультобъяснялка (без футажа)
- Насыщенные глубокие цвета, **не пастель**; **свой фон-мир на каждую сцену** (40 с в одном фиолетовом космосе отклонили).
- Глубина из 2D-слоёв, а не 3D-движка: форма + жёсткая теневая «луна» + светлый край; градиенты из 3–6 сплошных полос; лёгкая кривизна — ничего идеально круглого.
- Герой крупно в центре и взаимодействует (смотрит, фотографирует, разглядывает). Не-людей — взрослыми, не милыми.
- Действие показывать буквально: «программирует» = руки на светящейся клавиатуре + читаемый код с подсветкой.
- Переходы из сюжета: глитч-блоки собираются в экран следующей сцены, камера ныряет в телевизор и выныривает из следующего,
  предмет перелетает из сцены в своё место в следующей. Никаких простых слайдов, зумов и вжухов.
- Отклонено: пастель, однотонный фон, гладкие «3D-движок» градиенты, идеальная геометрия, милые пришельцы,
  маленький или неподвижный герой, статичная середина, подпись поверх уже подписанной графики.

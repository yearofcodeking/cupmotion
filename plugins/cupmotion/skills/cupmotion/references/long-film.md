# Длинный ролик (от 45 секунд): бриф режиссёра

Сильные длинные ролики делают не одним промптом, а брифом на 9 500–19 000 символов. Бриф не описывает видео —
он «нанимает съёмочную группу». Структура:

1. **Фильм одной строкой:** логлайн и что зритель должен почувствовать в конце.
2. **Референсы и входы:** видео, кадры, библиотека картинок (брать грамматику, не содержание); трек — использовать без изменений, сначала замерить доли.
   Доступные ключи API — только имена переменных из `.env`, бюджет, «расходуй экономно».
3. **Вид:** 3–5 строк — палитра, шрифт, фактура, язык камеры, запрещённые приёмы.
4. **Бит-лист:** 0–2 с — самый сильный образ; дальше акты с таймкодами, новая визуальная награда каждые 3–5 секунд; последний кадр подводит к первому.
5. **Работа по этапам:** `docs/style_guide.md` и `docs/shotlist.md` (каждый шот: кадры, камера, текст, звук) → стоп-кадры всех шотов и контакт-лист →
   аниматик в 960×540 с черновым звуком (поправить темп до полировки) → полная анимация, полировка, звук, финальный рендер.
6. **Субагенты по главам:** сначала написать `docs/ANIMATION_GUIDE.md`, чтобы все кодили в одном стиле (главы можно делать параллельно).
7. **Критика каждого шота** минимум в 3 круга: 3–5 стоп-кадров, оценки 1–10 (крючок, читаемость на 360 px, движение, композиция, глубина, синхрон, полировка),
   журнал `docs/review_log.md` с тремя главными проблемами; повторять до 8+.
8. **Сдача:** финальный MP4, проверка петли, постер, контакт-лист, исходники с README.

Приём для сложных сцен: видеомодель делает базовые кадры с персонажами и физикой, затем Claude перерисовывает поверх кодом — зритель видит только
кодовый слой. Требует доступа к видеомодели.
